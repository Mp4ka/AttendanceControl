## Найденные дефекты

### DEF-01. Кнопка «Назад» перекрывает строку состояния — исправлен (спринт 1)

| Поле | Значение |
|---|---|
| **Обнаружен** | 16.11.2026, при первом прогоне TC-02/TC-03 |
| **Серьёзность** | средняя (интерфейс, не блокирует работу) |
| **Причина** | `targetSdk 37`: система включает edge-to-edge, разметка не учитывала системные отступы |
| **Исправление** | `android:fitsSystemWindows="true"` в корневых `ScrollView`, скорректированы отступы |
| **Статус** | закрыт, проверен повторно |

Новых дефектов в спринте 2 не выявлено.

## Замечания по инструментам

- `uiautomator dump` не включает всплывающее сообщение `Snackbar` в иерархию,
  поэтому сообщения «Студент добавлен»/«Студент удалён» подтверждены скриншотами.
- Для ввода кириллицы в поля использовался ADBKeyboard (`ADB_INPUT_B64`),
  так как `adb shell input text` не поддерживает русские символы.
