## Найденные дефекты

### DEF-01. Кнопка «Назад» перекрывает строку состояния — исправлен

| Поле | Значение |
|---|---|
| **Обнаружен** | при первом прогоне TC-02/TC-03, 16.11.2026 |
| **Серьёзность** | средняя (интерфейс, не блокирует работу) |
| **Экран** | все экраны-заготовки |
| **Шаги** | Открыть «Студенты» на Android 17 → посмотреть верхнюю часть экрана |
| **Ожидаемо** | Кнопка «← Назад» ниже строки состояния |
| **Фактически** | Текст «Назад» накладывался на часы и иконки строки состояния |
| **Причина** | `targetSdk 37`: система включает режим edge-to-edge, а разметка не учитывала системные отступы |
| **Исправление** | Lead Developer добавил `android:fitsSystemWindows="true"` в корневые `ScrollView` и уменьшил верхние отступы |
| **Проверка после исправления** | пройдена: скриншоты `02_students.png` … `04_statistics.png` |
| **Статус** | закрыт |

## Как воспроизвести проверки

```powershell
# 1. Сборка
.\gradlew.bat assembleDebug

# 2. Установка на эмулятор
adb install -r app\build\outputs\apk\debug\app-debug.apk

# 3. Запуск и проверка экрана
adb shell am start -W -n ru.college.attendance/.MainActivity
adb shell uiautomator dump /sdcard/ui.xml
adb pull /sdcard/ui.xml screenshots/ui_main.xml
adb shell screencap -p /sdcard/shot.png
adb pull /sdcard/shot.png screenshots/01_main.png

# 4. Проверка логов на падения
adb logcat -d -b crash | Select-String "ru.college.attendance"
```
