# Спецификация ввода: студент

**Проект:** «Система контроля посещаемости студентов»
**Спринт:** 2 (День 2) — «Студенты и учебные группы»
**Автор:** Product Owner — Кургачёв Егор
**Дата:** 17.11.2026
**Основание:** US-02, US-03, US-04
**Тестовые данные:** студенты группы 2ИП-4-25 (Крытченко Максим, Кургачёв Егор,
Чепурнов Дмитрий)

Документ фиксирует поля студента, правила проверки ввода, тексты сообщений и примеры
корректных и ошибочных данных. По нему Lead Developer реализует форму, а QA составляет тест-кейсы.

## 1. Поля карточки студента

| Поле | Обязательное | Ограничения | Подсказка в форме |
|---|---|---|---|
| Фамилия | да | после `trim()` не пустая, не более 40 символов | «Фамилия» |
| Имя | да | после `trim()` не пустая, не более 40 символов | «Имя» |
| Группа | да | после `trim()` не пустая, не более 40 символов | «Группа (например, 2ИП-4-25)» |

Правила обработки:

- значения обрезаются по краям (`trim()`) перед проверкой и сохранением;
- регистр сохраняется как ввёл преподаватель, сравнение дубликатов — без учёта регистра;
- внутренние пробелы допустимы: «Анна Мария» — корректное имя;
- цифры и дефис в группе допустимы: «2ИП-4-25»;
- пустая строка и строка из одних пробелов считаются разными ошибками.

## 2. Сообщения об ошибках

| Ситуация | Текст ошибки | Где показывается |
|---|---|---|
| Поле не заполнено | «Заполните поле» | под соответствующим полем, красным |
| Поле состоит только из пробелов | «Поле не может состоять из пробелов» | под соответствующим полем |
| Значение длиннее 40 символов | «Слишком длинное значение (не более 40 символов)» | под соответствующим полем |
| Такой студент уже есть в группе | «Такой студент уже есть в этой группе» | под полем «Группа» |
| Попытка сохранить с ошибками | форма не закрывается, фокус на первом проблемном поле | — |

## 3. Сообщения после успешных действий

| Действие | Текст | Формат |
|---|---|---|
| Студент добавлен | «Студент добавлен» | короткое всплывающее сообщение (Snackbar) |
| Студент удалён | «Студент удалён» | короткое всплывающее сообщение (Snackbar) |
| Список пуст | «Пока нет студентов» + подсказка и кнопка «Добавить студента» | блок на месте списка |

## 4. Диалог удаления

- Заголовок: «Удалить студента?»
- Текст: «Удалить <Фамилия Имя> из списка? Отметки посещаемости этого студента тоже будут удалены.»
- Кнопки: «Удалить» (подтверждение), «Отмена».
- Удаление запускается кнопкой-корзиной на карточке или долгим нажатием на карточку.

## 6. Отображение списка

- карточка: инициалы в круге, «Фамилия Имя» жирным, группа — подписью;
- сортировка по фамилии, затем по имени (без учёта регистра);
- в заголовке экрана — счётчик «Студентов: N»;
- пустой список: вместо карточек показывается пустое состояние с кнопкой добавления;
- после добавления или удаления список обновляется сразу, без перезапуска приложения.

## 7. Ограничения спринта

- данные хранятся в памяти приложения и исчезают после полного закрытия (Room — спринт 4);
- группы задаются текстом, отдельного справочника групп пока нет;
- редактирование существующего студента не входит в спринт 2 (только добавление и удаление).
