# Спецификация статистики и истории

**Проект:** «Система контроля посещаемости студентов»
**Спринт:** 5 (День 5) — «Статистика, фильтрация и надёжность»
**Автор:** Product Owner — Кургачёв Егор
**Дата:** 20.11.2026
**Основание:** US-08, US-09

Документ фиксирует показатели, фильтры и поведение экрана при пустых данных.

## 1. Показатели

| Показатель | Как считается |
|---|---|
| **Занятий** | количество уникальных пар «дата + дисциплина» среди отфильтрованных отметок |
| **Присутствий** | число отметок со статусом «Присутствовал» |
| **Пропусков** | число отметок со статусом «Отсутствовал» |
| **Опозданий** | число отметок со статусом «Опоздал» |
| **Записей истории** | общее число отфильтрованных отметок |

Сумма присутствий, пропусков и опозданий равна числу записей истории.
Количество занятий может быть меньше числа записей: на одном занятии отмечается несколько студентов.

## 2. Фильтры

| Фильтр | Значения | Поведение |
|---|---|---|
| Группа | «Все группы» + группы из списка студентов | при выборе группы список студентов сужается до её состава |
| Студент | «Все студенты» + студенты выбранной группы | показывает только его отметки |
| Дата | «Все даты» + даты из истории | оставляет отметки одного занятия |

Фильтры комбинируются: группа + студент + дата применяются одновременно.
Сброс — выбрать «Все группы», «Все студенты», «Все даты».

## 3. История

- строка: «дата · дисциплина», ниже — фамилия и имя студента, справа — статус;
- статус выделен цветом: присутствие — зелёный, пропуск — красный, опоздание — оранжевый;
- сортировка: сначала новые даты, внутри даты — по дисциплине;
- список прокручивается, количество записей показано в заголовке.

## 4. Пустые состояния

| Ситуация | Что видно |
|---|---|
| Отметок нет совсем | показатели 0, «История», «Отметок пока нет» и подсказка отметить занятие |
| Под фильтры ничего не подошло | показатели 0, «По выбранным фильтрам ничего не найдено», подсказка изменить фильтры |

## 6. Ограничения спринта

- отдельного экрана «История» нет: история показывается на экране статистики;
- фильтр по дате выбирается из дат, которые уже есть в отметках;
- экспорт отчётов и графики не предусмотрены;
- данные считаются по локальной базе устройства.
