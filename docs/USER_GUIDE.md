# Инструкция пользователя

**Приложение:** AttendanceControl — контроль посещаемости студентов
**Версия:** 0.5.0 (спринт 5)
**Дата:** 20.11.2026

## 1. Первый запуск

1. Откройте приложение — появится главное меню с разделами «Студенты»,
   «Отметить посещаемость» и «Статистика».
2. Пока студентов нет, разделы занятия и статистики показывают подсказки:
   сначала добавьте студентов.

## 2. Студенты

1. Главное меню → «Студенты».
2. Нажмите «Добавить студента».
3. Заполните фамилию, имя и группу (например, 2ИП-4-25) и нажмите «Сохранить».
4. Пустые поля, пробелы, слишком длинные значения и дубликаты отклоняются с сообщением.
5. Удалить студента можно корзиной на карточке — приложение спросит подтверждение.
   Вместе со студентом удаляются его отметки.

## 3. Занятие и отметки

1. Главное меню → «Отметить посещаемость».
2. Выберите группу из списка, проверьте дату (по умолчанию сегодня) и введите дисциплину.
3. Нажмите «Перейти к отметке».
4. Для каждого студента выберите статус: «Присутствовал», «Отсутствовал» или «Опоздал».
5. Нажмите «Сохранить отметки» — появится сообщение «Отметки сохранены».
6. Если отметить не всех, приложение попросит «Отметьте всех студентов».
7. Чтобы вернуться к занятию позже, снова выберите ту же группу, дату и дисциплину —
   сохранённые статусы подставятся автоматически.

## 4. Статистика

1. Главное меню → «Статистика».
2. Сверху видны четыре показателя: занятия, присутствия, пропуски и опоздания.
3. Ниже — история отметок: дата, дисциплина, студент и статус.
4. Фильтры:
   - «Группа» — оставить одну группу;
   - «Студент» — показать только его отметки;
   - «Дата» — оставить одно занятие.
5. Чтобы сбросить фильтры, выберите «Все группы», «Все студенты» и «Все даты».

## 5. Что важно знать

- данные хранятся только на этом устройстве и не пропадают после закрытия приложения;
- к занятию возвращаются по группе, дате и дисциплине: отдельного списка занятий нет;
- студента можно добавить и удалить, но нельзя отредактировать;
- приложение работает без интернета.

## 6. Если что-то пошло не так

| Ситуация | Что сделать |
|---|---|
| «Пока нет студентов» | добавьте студентов в разделе «Студенты» |
| «Отметьте всех студентов» | выберите статус каждому студенту в списке |
| «Такой студент уже есть в этой группе» | проверьте фамилию и группу или измените группу |
| «По выбранным фильтрам ничего не найдено» | сбросьте фильтры на «Все …» |
