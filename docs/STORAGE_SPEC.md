# Спецификация хранения данных

**Проект:** «Система контроля посещаемости студентов»
**Спринт:** 4 (День 4) — «Постоянное хранение данных»
**Автор:** Product Owner — Крытченко Максим
**Дата:** 19.11.2026
**Основание:** US-10

Документ фиксирует, какие данные сохраняются, где они лежат, как ведёт себя первый запуск
и что происходит при удалении студента.

## 1. Что сохраняется

| Данные | Поля | Комментарий |
|---|---|---|
| Студенты | `id`, `firstName`, `lastName`, `groupName` | добавляются и удаляются на экране «Студенты» |
| Отметки | `id`, `studentId`, `lessonDate`, `subject`, `status` | сохраняются на экране отметки посещаемости |

Отдельная сущность занятия не создаётся: занятие определяется группой, датой и дисциплиной,
а дата и дисциплина хранятся прямо в отметке.

## 2. Где хранятся данные

- локальная база SQLite `attendance.db` во внутреннем каталоге приложения (`databases/`);
- доступ только у приложения, без сети и синхронизации;
- в базе две таблицы: `students` и `attendance`;
- уникальный индекс `(studentId, lessonDate, subject)` гарантирует одну отметку на студента и занятие;
- внешний ключ `attendance.studentId → students.id` с `ON DELETE CASCADE`.

## 3. Правила сохранения

- каждое действие (добавление студента, удаление, сохранение отметок) сразу пишется в базу;
- после закрытия и повторного запуска приложения данные остаются на месте;
- повторное сохранение занятия заменяет прежние статусы;
- удаление студента удаляет и его отметки — без «висящих» записей в статистике.

## 4. Первый запуск и пустая база

1. При первом запуске база создаётся пустой, без демонстрационных записей.
2. Экран «Студенты» показывает «Пока нет студентов» и кнопку добавления.
3. Экран «Занятие» сообщает, что сначала нужно добавить студентов.
4. Ошибок и падений при пустой базе быть не должно.

## 5. Ограничения спринта

- версия схемы — 1; миграции понадобятся только при изменении структуры таблиц;
- данные хранятся только на одном устройстве;
- резервное копирование и экспорт не предусмотрены;
- суммарная статистика по отметкам появится в спринте 5.
