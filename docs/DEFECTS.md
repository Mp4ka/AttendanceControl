## DEF-01. Кнопка «Назад» перекрывает строку состояния

| Поле | Значение |
|---|---|
| **Обнаружен** | 16.11.2026, прогон TC-02/TC-03 |
| **Серьёзность** | средняя (интерфейс) |
| **Экран** | экраны-заготовки |
| **Шаги** | Открыть раздел на Android 17 и посмотреть верхнюю часть экрана |
| **Ожидаемо** | Кнопка ниже строки состояния |
| **Фактически** | Текст «Назад» накладывался на часы и иконки |
| **Причина** | `targetSdk 37`: принудительный edge-to-edge, разметка не учитывала системные отступы |
| **Исправление** | `android:fitsSystemWindows="true"` в корневых контейнерах, скорректированы отступы |
| **Проверка** | повторный прогон TC-02/TC-03, скриншоты 01–04 |
| **Статус** | закрыт |

## DEF-03. Экран статистики падал при открытии

| Поле | Значение |
|---|---|
| **Обнаружен** | 20.11.2026, первый прогон TC-19 |
| **Серьёзность** | критическая (экран недоступен) |
| **Экран** | «Статистика» |
| **Шаги** | Главное меню → «Статистика» |
| **Ожидаемо** | Экран с показателями и историей |
| **Фактически** | Приложение закрывалось с `UnknownFormatConversionException: Conversion = ' '` |
| **Причина** | в строке `history_lesson` был повреждён спецификатор формата: `%1$s · %2$s` превратился в `%1 · %2` |
| **Исправление** | строка формата восстановлена, `history_count` приведён к `%1$d`; сборка перепроверена |
| **Проверка** | повторный прогон TC-19, TC-18 и TC-23; падений в `logcat` нет |
| **Статус** | закрыт |

## Как фиксируются новые дефекты

1. QA воспроизводит проблему на сборке спринта.
2. В таблицу добавляется запись: экран, шаги, ожидаемый и фактический результат.
3. LD исправляет и указывает причину.
4. QA повторяет шаги и меняет статус на «закрыт».
