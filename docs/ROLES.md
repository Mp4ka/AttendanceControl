**LD — Крытченко Максим**, **QA — Чепурнов Дмитрий**.

### 4.1. Что сделано

- создан проект `AttendanceControl` (Kotlin, XML, AGP 9.4.1, Gradle 9.6.0);
- собран и запущен `app-debug.apk` на эмуляторе Android 17 (API 37);
- готов главный экран: название, подзаголовок, три карточки-раздела;

- подготовлены 3 тест-кейса, прогон 3/3, найден и исправлен дефект DEF-01;
- репозиторий Git инициализирован, настроен `.gitignore`, у каждого участника есть коммиты.

### 4.2. Что осталось / переходит в спринт 2

- US-02 — список студентов; US-03 — добавление с валидацией; US-04 — удаление с подтверждением;
- экраны-заготовки пока без функциональности: в них только описание будущих возможностей;
- хранение данных в памяти (Room — только спринт 4), поэтому после перезапуска данные теряются;
- тест-кейсы TC-05 … TC-10 ждут реализации функций.

### 4.3. Ошибки и риски

| Что | Статус / действие |
|---|---|
| DEF-01: кнопка «Назад» перекрывала строку состояния | исправлено (`fitsSystemWindows`), проверено |
| Первая сборка скачивает зависимости из сети | нужен интернет при первом `assembleDebug`; далее сборка идёт из кэша |
| `local.properties` содержит путь к SDK | файл в `.gitignore`, в репозиторий не попадает |
| Отдельные экраны не имеют общей темы оформления для будущих форм | при добавлении форм использовать стили из `themes.xml` |

| **LD (Крытченко Максим)** | `data class Student`, экран списка и форма добавления, вывод списка, удаление с подтверждением | Студент добавляется, отображается и удаляется; пустые поля отклоняются |
| **QA (Чепурнов Дмитрий)** | Тест-кейсы TC-05…TC-10, проверка сборки после интеграции, ревью ветки `feature/add-student` | Тест-кейсы оформлены, прогон выполнен, дефекты записаны |

### 4.5. Правила работы с Git

- одна ветка на задачу: `feature/add-student`, `feature/students-list`, `docs/user-stories`, `fix/...`;
- сообщения коммитов — по существу: «Добавлен экран списка студентов», а не «готово»;
- перед слиянием другой участник смотрит код и проверяет, что `assembleDebug` проходит;
- `main` всегда содержит рабочую версию; после спринта — тег `v0.x.0-sprintN`;
- персональные данные студентов в репозиторий не добавляются.
